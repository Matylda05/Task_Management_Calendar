# Task Management Calendar

## Opis
Aplikacja webowa umożliwiająca zarządzanie zadaniami w widoku kalendarza miesięcznego. Projekt pozwala użytkownikowi dodawać, edytować i organizować zadania w przejrzysty sposób, łącząc funkcjonalność listy zadań z wizualizacją kalendarzową.

---

## Funkcjonalności
- dodawanie i usuwanie zadań
- edycja istniejących zadań
- widok kalendarza miesięcznego
- przejrzysta organizacja zadań w czasie

---

## Technologie
- HTML
- CSS
- JavaScript
- Express.js
- SQL

## Cel projektu
Celem projektu było stworzenie prostej aplikacji do zarządzania zadaniami z naciskiem na:
- czytelny interfejs użytkownika

- praktyczne wykorzystanie technologii webowych

## Jak uruchomić projekt

1. Sklonuj repozytorium:
  git clone https://github.com/Matylda05/Task_Management_Calendar.git
2. Przejdź do folderu projektu:
  cd Task_Management_Calendar
3. Zainstaluj zależności:
  npm install
4. Uruchom aplikację:
  npm start
5. Otwórz w przeglądarce:
  http://localhost:4000
